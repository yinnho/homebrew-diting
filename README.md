# homebrew-diting

Homebrew tap for [diting](https://github.com/yinnho/diting) — the engine-first browser for AI agents.

```bash
brew trust yinnho/diting
brew install yinnho/diting/diting
```

Verify after install:
```bash
diting --version   # diting 0.7.0
diting doctor      # full environment self-check
```
